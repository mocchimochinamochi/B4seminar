# surveybot (Go版)

元のPythonスクリプトをGoに移植し，複数ワーカーによる並列実行に対応させたものです。

## できること

- 32種類の性格ペルソナを重み付けに従って割り当て，Gemini APIに19問のアンケートを投げて回答を収集
- `-workers` で指定した数のゴルーチンが並列にAPIへリクエストを送信
- 複数のAPIキーをワーカー間で安全にローテーション（429レート制限を検知したら自動的に次のキーへ）
- 中断・再実行に対応（CSVに記録済みのTrialはスキップ。並列実行で完了順が入れ替わっても安全）
- 完了後，設問ごとの回答分布をSVGバーチャートとして`plots/`に出力（matplotlib不要・外部ライブラリ依存なし）

## ビルド

```bash
go build -o surveybot .
```

外部依存ライブラリは一切使用していません（標準ライブラリのみ）。

## 実行方法

1. `.env.example` を `.env` にコピーし，実際のAPIキーを設定します（カンマ区切りで複数指定可）。

   ```
   GEMINI_API_KEYS=your_key_1,your_key_2,your_key_3
   ```

2. 実行:

   ```bash
   ./surveybot
   ```

3. 主なオプション（すべて省略可。`-h` で一覧表示）:

   | フラグ | 既定値 | 説明 |
   |---|---|---|
   | `-n` | 100 | 総試行回数 |
   | `-workers` | APIキー数 | 並列ワーカー数。大きくしすぎるとレート制限に当たりやすくなります |
   | `-model` | gemini-3-flash-preview | 使用するモデル名 |
   | `-csv` | survey_results_persona.csv | 出力CSVパス |
   | `-plots` | plots | グラフ出力ディレクトリ |
   | `-env` | .env | .envファイルのパス |
   | `-max-retries` | 8 | 1試行あたりの最大リトライ回数（レート制限の待機は除く） |
   | `-timeout` | 60 | 1リクエストのタイムアウト秒数 |

   例: キー3本・ワーカー6並列で50件だけ実行する場合

   ```bash
   ./surveybot -n 50 -workers 6
   ```

## 並列処理の仕組み

- `buildTrials` で生成した全Trialを1つのジョブチャネルに積み，指定数のワーカーゴルーチンがそこから取り出して処理します。
- 結果は1本の書き込みゴルーチンに集約してCSVへ追記するため，ファイル破損やレースは発生しません（`go test -race` で確認済み）。
- APIキーのローテーションは`KeyManager`がmutexで保護しており，複数ワーカーから同時に呼ばれても安全です。
- Ctrl+C（SIGINT/SIGTERM）で安全に中断できます。実行中のリクエストは完了してから停止します。再実行すれば，CSVに記録済みのTrialはスキップされます。

## テスト

モックHTTPサーバーを使い，並列実行・レート制限時のキーローテーション・CSV書き込みの安全性・SVG生成を検証するテストを同梱しています。

```bash
go test ./... -race
```

## 元のPython版との違い

- 並列実行に対応（Pythonの逐次forループ → Goのワーカープール）。
- グラフ生成はmatplotlib(PNG)からSVG（外部ライブラリ不要・自前実装）に変更。見た目は簡素ですが，ブラウザ等でそのまま開けます。
- リトライ・レジューム・ペルソナ配分ロジックは元のPython版とできるだけ同じ挙動になるよう実装しています（ただし重み×Nが厳密に.5になるケースの四捨五入方式はPythonの「偶数への丸め」とGoの「0から離れる方向への丸め」で僅かに異なる場合があります。実用上の影響はありません）。
